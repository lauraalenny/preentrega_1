# 💻 TechPastel - Tienda de Tecnología Pastel

Este proyecto es un **Trabajo Práctico** de desarrollo web que simula una tienda online de productos tecnológicos (periféricos y setup) con una estética moderna basada en colores pasteles. El sitio está estructurado de forma multipágina, garantizando una excelente experiencia de usuario y un diseño totalmente adaptativo.

---

## 🛠️ Tecnologías y Requisitos Implementados

El proyecto cumple estrictamente con las consignas solicitadas:

1. **Estructura Semántica de HTML:** Dividido de forma correcta utilizando etiquetas semánticas principales como `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.
2. **Formulario de Contacto Funcional:** Implementado con validación nativa y conectado a **Formspree** para el procesamiento real del envío de datos directamente al correo electrónico.
3. **Estilos CSS Externos (`styles.css`):**
   - Estilizado completo de secciones de navegación, cabecera y pie de página.
   - Integración correcta de tipografías desde **Google Fonts** (Fuente: *Roboto*).
   - Aplicación de propiedades de fondo avanzados empleando gradientes o degradados lineales pastel (`linear-gradient`).
4. **Diseño Responsivo moderno:**
   - **Flexbox:** Utilizado en la sección *Productos* para lograr una distribución de tarjetas dinámica y flexible.
   - **CSS Grid:** Utilizado en la sección *Reseñas* para lograr un diseño cuadriculado ordenado y estético.
   - **Media Queries:** Implementadas en la sección *Contacto* y componentes globales para asegurar la adaptabilidad en dispositivos móviles.
5. **Contenido Multimedia y Navegación:**
   - Estructura multipágina con enlaces relativos funcionales que permiten interactuar entre las diferentes secciones de manera limpia.
   - Inclusión de archivos multimedia locales optimizados.

---

## 📂 Estructura del Proyecto

```text
├── index.html          # Página de Inicio (Hero y multimedia)
├── productos.html      # Catálogo de productos (Maquetado con Flexbox)
├── resenas.html        # Opiniones de usuarios (Maquetado con CSS Grid)
├── contacto.html       # Formulario de contacto (Responsive con Media Queries)
├── styles.css          # Estilos generales del sitio
├── README.md           # Documentación del proyecto (Este archivo)
└── img/                # Carpeta contenedora de recursos multimedia locales
```
